# Wax & Groove — Interactive Record Store

A fully interactive front-end build for a fictional independent record shop, built with plain HTML, CSS, and JavaScript (no frameworks). Created as part of a frontend internship task (Week 3: Integrating JavaScript for Interactive User Experience).

## ✨ Interactive Features

| Feature | Description |
|---|---|
| 🎚️ Genre filter | Filter the record grid by genre with a live results count |
| ❤️ Wishlist | Toggle records into a wishlist, tracked in the header badge |
| 🛒 Shopping cart | Add/remove items, adjust quantity, running total, slide-in drawer |
| 🎵 FAQ accordion | Expand/collapse answers independently |
| 💬 Review carousel | Auto-advancing testimonial slider with dots and arrow controls |
| ✉️ Newsletter form | Inline email validation with no page reload |
| 🌗 Theme toggle | Switch between dark and light color schemes instantly |
| ⬆️ Back-to-top | Appears after scrolling, smooth-scrolls back up |
| 🎬 Scroll reveal | Sections fade/slide in as they enter the viewport |

## 🛠️ Built With

- **HTML5** — semantic markup (`header`, `main`, `section`, `article`, `aside`, `form`)
- **CSS3** — custom properties for theming, Flexbox, Grid, transitions
- **Vanilla JavaScript** — DOM manipulation, event delegation, `IntersectionObserver`, form validation via the Constraint Validation API
- **Google Fonts** — Space Grotesk, Inter, IBM Plex Mono
- No frameworks, no build tools, no dependencies

## 🌐 Deployment (GitHub Pages)

1. Go to your repo → **Settings** → **Pages**
2. Under **Source**, select the `main` branch and `/ (root)` folder
3. Save — your site will be live at `https://yourusername.github.io/your-repo-name/`
